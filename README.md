Projeto desenvolvido em Microsoft Excel como parte de um projeto de estudo da DIO, com o objetivo de criar uma ferramenta para auxiliar na organização das informações necessárias para a preparação da Declaração de Imposto de Renda Pessoa Física (IRPF).
A proposta é centralizar, em uma única planilha, informações pessoais do titular, informes de rendimentos bancários e registros de entradas financeiras, facilitando a organização dos documentos e dados que poderão ser utilizados posteriormente na elaboração da declaração.
o objetivo do projeto é desenvolver uma ferramenta simples e estruturada em Excel para organizar informações relacionadas à declaração de Imposto de Renda, reduzindo a necessidade de consultar diferentes fontes e documentos durante o processo de preparação das informações.
A planilha está organizada em três abas principais: titular, informes e notas e cada aba possui uma finalidade específica dentro do processo de organização das informações.
Na aba titular, concentra os principais dados cadastrais do contribuinte. A planilha utiliza validação de dados para campos de resposta objetiva, "sim" ou "não" e isso ajuda a padronizar o preenchimento e reduzir inconsistências na entrada das informações.
A aba informes é destinada à organização dos informes de rendimentos bancários. A planilha realiza automaticamente a consolidação dos valores informados nos bancos. O total é calculado a partir dos valores cadastrados nas respectivas instituições financeiras, utilizando uma fórmula de soma no Excel. Dessa forma, o total é atualizado de acordo com os valores preenchidos pelo usuário.
a aba notas foi estruturada para registrar as entradas financeiras mês a mês. O projeto utiliza uma lista padronizada para classificação das entradas: holerite, CNPJ, freelance. A utilização de uma lista de seleção facilita o preenchimento e mantém um padrão para classificação das receitas. A estrutura permite registrar diferentes entradas financeiras ao longo do período, facilitando a posterior consulta e organização dos valores.
O desenvolvimento do projeto envolveu diferentes recursos do Microsoft Excel, incluindo: Organização e estruturação de dados; Formatação de planilhas; Fórmulas; Funções de soma; Validação de dados; Listas suspensas; Tabelas; Base auxiliar de informações; Referenciamento de dados; Organização de documentos e informações financeiras.
O projeto pode ser utilizado como uma ferramenta de apoio na etapa de organização das informações para a declaração de Imposto de Renda. Ao centralizar os dados, o usuário consegue consultar de maneira mais organizada. Isso facilita a preparação das informações antes do preenchimento efetivo da declaração.
O desenvolvimento deste projeto permitiu aplicar conhecimentos relacionados à utilização do Excel para organização e tratamento de informações financeiras. Entre os principais aprendizados estão: Estruturação de uma planilha para uma necessidade prática; Organização de dados em diferentes abas; Criação de bases auxiliares; Utilização de validação de dados; Criação de listas suspensas; Utilização de fórmulas para automatização de cálculos; Consolidação de informações; Padronização de dados; Organização de documentos e informações para facilitar consultas futuras.
O projeto também demonstra como o Excel pode ser utilizado para transformar informações que estão dispersas em uma estrutura mais organizada e funcional.
